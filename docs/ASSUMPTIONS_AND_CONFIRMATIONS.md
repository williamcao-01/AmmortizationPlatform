# 当前数据约束

- 运行时唯一输入为 `data/customer_snapshot/` 中三份受控 Excel：资产台账（`20260812`）、资产配置（`20260819`）和组织机构表（`20260810`）。
- 不加载历史 Excel、旧 CSV、旧 SQLite 或其他运行时输入；组织层级来自组织机构表，资产归属仍以台账的所属单位字段为准。

- SAP 预测结果由客户人工核验；系统提供逐资产、逐月和逐规则记录。

# 待客户确认的业务口径

- `2025-01` 至 `2026-05` 是基于 `2026-06` 台账快照和月度驱动的反向重建值，不应在未核验前表述为 SAP 历史实际。

- Neo4j Community 是运行时必需组件；DeepSeek 仅用于基于已计算证据的业务语言表达。通用知识问答默认不向外部模型发送证据，启用前需获得数据外发批准。
